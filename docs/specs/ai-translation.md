## 1. 结论（先读）

**翻译是选区即时理解工具**；整本/按章译是后续长任务，**共用同一套翻译偏好**。

| 项 | 已定默认（开卷） |
|----|------------------|
| 目标语言 | **简体中文** |
| 方向策略 | **固定译到目标语言** |
| 译文风格 | **通顺意译** |
| 显示方式 | **仅译文**（原文一条可折叠） |
| 上下文 | **关**（仅选区） |
| 写入笔记 | **仅译文** |
| 结果卡 | 支持**本次目标语言**覆盖 + 再译 |

**不做**：中译中改写当「翻译」；无设置时用「猜文种」作为唯一策略（可作辅助检测，不得覆盖用户目标语言）。

## 2. 目标与非目标

### 做

- 选区「翻译」读全局翻译偏好 + 结果卡临时覆盖。  
- 设置 → AI 助手 → **翻译**分组（或二级「翻译偏好」页）。  
- 原文已是目标语言时的明确提示，避免无效生成。  
- 排版可读的译文结果（分段 / 标题样式，见结果 UI）。  
- 为 M4 整本/按章译预留同一偏好字段。  

### 不做（本能力内）

- 漫画 OCR / 气泡译。  
- 账号云翻译、内置机翻密钥。  
- 句级对齐、交互式双语阅读模式（**远**）。  
- 与系统翻译偏好双向同步。  
- 第四根 Tab 或独立「翻译 App」。

## 4. 设置项（权威）

### 4.1 目标语言 `targetLanguage`

| 值 | 文案 | v1 |
|----|------|-----|
| `zh-Hans` | 简体中文 | **默认** |
| `en` | English | 有 |
| `zh-Hant` | 繁體中文 | 有 |
| `ja` | 日本語 | 有 |
| `ko` | 한국어 | 有 |
| 其他 | — | **中** 再扩 |

存储用 BCP 47 风格短码；UI 显示中文/本地名。

### 4.2 方向策略 `directionMode`

| 值 | 文案 | 行为 |
|----|------|------|
| `fixedTarget` | 固定译到目标语言 | **默认**。始终译向 `targetLanguage`。 |
| `smartBidi` | 智能双向 | 原文脚本 ≈ 目标语言 → 译向「对侧」默认语言（中↔英）；否则译向目标语言。 |

**v1 实现 `fixedTarget` 即可**；`smartBidi` 可同字段预留，UI 可先只展示「固定」或两项都做。

**原文已是目标语言**（启发式：与目标语言脚本高度一致）：

- **不**自动调用模型做同语改写。  
- 结果卡展示说明 + 快捷「改译为 English」（若当前目标为简中）或「改译为简体中文」（若当前目标为 en）。  
- 用户显式换目标语言后再译。

### 4.3 译文风格 `style`

| 值 | 文案 | 说明 |
|----|------|------|
| `natural` | 通顺意译 | **默认**；适合通读 |
| `literal` | 偏直译 | 少意译，保留结构，适合术语 |
| `academic` | 学术意译 | 文言/史论用现代汉语说清，不硬造古风 |

### 4.4 显示方式 `displayMode`

| 值 | 文案 | 说明 |
|----|------|------|
| `targetOnly` | 仅译文 | **默认**；原文仍以折叠行展示（可点开） |
| `bilingual` | 对照 | 上原文（可折）+ 下译文；v1 不做句级对齐 |

### 4.5 选区上下文 `includeContext` / `contextChars`

| 值 | 默认 |
|----|------|
| `includeContext` | **false** |
| `contextChars` | 100（开启时，前后各不超过该字数，按字符截断） |

开启后 prompt 可带「选区前后文」，并标明哪一段是待译正文。

### 4.6 写入笔记格式 `noteFormat`

| 值 | 文案 | 默认 |
|----|------|------|
| `translationOnly` | 仅译文 | **是** |
| `sourceAndTranslation` | 原文 + 译文 | 否 |

## 5. 选区结果卡交互

### 5.1 结构

```text
┌─────────────────────────────────────┐
│ 翻译    [简体中文 ▾]     停止 / 关闭 │
├─────────────────────────────────────┤
│ 原文（一行折叠 / 点开全文）           │
│                                     │
│ 译文（流式；AiResultBody 排版）       │
├─────────────────────────────────────┤
│ 复制  写入笔记  再译  系统翻译         │
└─────────────────────────────────────┘
```

### 5.2 行为

1. 打开：关闭选区菜单；用**全局偏好**生成；顶栏显示当前目标语言。  
2. 切换顶栏目标语言：更新**本次会话**覆盖（不写回设置，除非提供「设为默认」—— v1 **不做**设为默认）。  
3. 切换后：自动触发一次再译（或仅启用「再译」按钮；**推荐自动再译**并取消上一次请求）。  
4. 再译：同参数重跑；取消进行中的请求。  
5. 复制：`targetOnly` 复制译文；`bilingual` v1 仍复制译文（复制对照 **中**）。  
6. 写入笔记：按 `noteFormat`；需有效 CFI；无划线则创建默认下划线再写 note（与词典一致）。  
7. 系统翻译：关闭 sheet → 平台能力；忽略 AI 翻译偏好。  
8. 关闭 / 停止：cancel token；已生成文字可保留到 dismiss。流式输出只有收到 Provider 的正常完成事件才进入完成态；token 截断、异常 EOF、空闲超时和取消都保留已显示文字但禁用复制/写入笔记，并提示重试。

### 5.3 状态与文案

| 场景 | 文案草案 |
|------|----------|
| 生成中 | 生成中… |
| 原文≈目标语言 | 原文已是{目标语言名}。无需同语改写。 |
| 快捷改译（目标为简中） | 改译为 English |
| 快捷改译（目标为 en） | 改译为简体中文 |
| 失败 | 可读错误 + 可再译 / 系统翻译 |
| 无 AI | 不进本卡；直接系统翻译或提示启用 AI（与现网一致） |
| 复制成功 | 已复制 |
| 笔记成功 | 已写入笔记 |

## 6. Prompt 边界（实现约束）

### 6.1 输入

- **待译正文**：选区文本（截断见 `AiLanguageService.maxInputChars`）。  
- **可选上下文**：仅当 `includeContext`；明确标注「以下为待译正文」。  
- **目标语言**：解析后的语言名（如「简体中文」「English」）。  
- **风格**：映射到简短指令（意译 / 直译 / 学术意译）。  
- 选区、前后文、书名、作者和章节名全部是不可信引用数据，必须放在 user 消息的显式边界内；不得把电子书元数据直接插入 system prompt。

### 6.2 输出

- **只输出译文**（`targetOnly` / 默认）；不要标题、不要全文对照（对照由 UI 拼原文）。  
- **禁止**把「翻译」做成同语润色（中译中、英译英）。  
- 专有名词：目标为中文时可用通行译名；目标为英文时用通行英文。  

### 6.3 与「自动猜文种」关系

- **不得**用猜文种覆盖用户选择的目标语言。  
- 猜文种仅用于：  
  - 判断「原文是否已是目标语言」；  
  - `smartBidi` 的对侧语言（若实现）。

## 7. 数据

建议挂在 `AiSettings`（或并列 `AiTranslationPreferences` 写入同一 `ai_settings.json` 非机密文件）：

```text
translation:
  targetLanguage: zh-Hans | en | zh-Hant | ja | ko | …
  directionMode: fixedTarget | smartBidi
  style: natural | literal | academic
  displayMode: targetOnly | bilingual
  includeContext: bool
  contextChars: int
  noteFormat: translationOnly | sourceAndTranslation
```

| 数据 | 存储 | WebDAV 备份 |
|------|------|-------------|
| 翻译偏好 | `ai_settings.json` | **否**（与 AI 连接配置一致，属本机增强偏好） |
| API Key | 安全存储（按服务商） | **否** |
| 选区译结果 | 不默认持久化；写入笔记则进 annotations | 笔记 **是** |
| 整本译缓存 | M4 另表 / 文件 | **否**（v1） |

结果卡「本次目标语言」仅内存，关闭 sheet 即丢。

## 8. 分层

```text
AiSettings / translation 字段
  → AiSettingsController（读写偏好）
  → AiLanguageService（拼 prompt，读偏好 + 本次 override）
  → BookReaderController.streamLanguageAssist(…, translationOverride?)
  → book_ai_language_sheet（展示、本次语言、再译）
```

- UI **不**拼 prompt、**不**持有 HTTP。  
- 系统翻译仍走 `performPlatformLanguageAction`。

## 9. 视觉

- 设置：与 AI 助手同管理型子页语言；组间距 ≥ 组内两倍；**单 Column 进 AppSettingsGroup**，避免多余 hairline（历史问题）。  
- 结果卡：沿用 `AppBottomSheet` 单层表面；正文用 `AiResultBody`（或等价）分段，不把 Markdown 原样糊成一行。  
- 目标语言：顶栏 `AppMenuButton` / 选择条，桌面可锚定菜单。  
- token：`AppSpacing` / `AppRadii` / 语义色；强调色仅用于主操作与选中。
