## 目标

**开卷** App 内已导入条目的浏览与管理：漫画（页图）与图书（reflow）混排，通过「类型」筛选。

## 范围

- **做**：网格/列表、导入、打开（按 `kind` 路由）、搜索/排序/筛选（含类型）、多选、**书单**二级、**合集**。  
- **不做**：跳转到另一 App；按品牌身份切库；封面卡上的单独「…」操作入口。

## 信息架构

```text
书库
  · 主区：单本（网格 / 列表）+ 合集卡混排（合集排最前）
  · 左上角：当前书籍范围（默认「全部书籍」）与下拉筛选
  · 右上角：更多（网格/列表、排序、书单、合集）
  · 主区上方：标题搜索
  · 二级入口：
      - 书单 → 长清单管理（lists.md）
      - 合集 → 拼贴盒管理（collections.md）
```

- 导入扩展名与导入方式分层维护；当前本地文件 / 文件夹扫描复用统一导入管线，格式矩阵见 [import.md](./import.md)。
- Android SAF 不可靠识别 EPUB MIME；Android 文件选择器允许浏览全部文件，返回应用后再按扩展名严格接收当前格式白名单。其他平台继续在选择器阶段过滤扩展名。
- EPUB 按内容自动路由：Dart ZIP/OPF spine 抽样（`EpubKindProbe`）— 正文 → book；抽样中绝大多数章节为低文字页图 → comic（`EpubImportRouter`）；普通封面和零散插图不参与漫画判定。页图路径不经 WebView。
- **书单**与**合集**入口文案、图标必须区分（列表 vs 拼贴盒）。

## 打开路由

```text
点单本 → 按 item.kind 进入对应引擎
  kind=book  → BookReaderScreen
  kind=comic → ComicReaderScreen

点合集卡 → 合集内容页 → 再点成员 → 引擎
点书单 → 书单内容列表 → 再点成员 → 引擎
```

## 卡片 / 空态 / 视觉

- **单本卡**：封面 + 两行标题；可选进度 / 格式角标。无封面上的「…」按钮。  
- **合集卡**：单本卡同尺寸外框 + 内部小封面拼贴；见 collections.md。目录合集卡长按出管理菜单（无角标按钮）。  
- 空态文案：「导入图书或漫画文件」；导入操作统一从右下角加号进入。
- 搜索框和其他短文本编辑使用输入组件角色 `inputText`（Mobile 16/22、Desktop 14/20），不继承页面 `body`；封面网格标题使用 `gridTitle`（14/20、w500），标题区必须限制为组件约定的单行高度并省略。
- **顶栏分层**：
  - 标题字号收敛为区段标题；有内容时显示当前书籍范围（默认「全部书籍」）和下拉箭头。
  - 更多菜单承载网格/列表切换、排序方式、书单与合集；点击排序方式后打开二级选择面板。
  - 搜索独立置于标题下方，不再和筛选胶囊并排堆叠。
  - 导入固定在右下角；点击加号后以分段动画向上展开导入快捷菜单，本地文件已接入，自动扫描、云端存储、WiFi 传书、在线书库预留为后续入口。
  - 空库时隐藏搜索与低频管理入口，仅保留标题、空态和右下角导入。
- Token 与间距见 DESIGN_FOUNDATION。

## 多选

- 批量：删除、加入/移出书架、加入书单、加入合集。
- **进入多选**：长按单本封面；点选切换；不在封面上挂单独操作钮。
- 不在多选里混淆「创建书单」与「创建合集」的主按钮文案。
- **封面选中态**：仅角标勾选（实心 `check_circle` / 空心圆）；**不要**封面外加粗强调色描边。多选未选中时角标用白描边圆（带轻阴影）。  
- **封面卡悬停 / 按压**：禁用 Material 泼墨与灰雾 overlay（盖在封面上很脏）；可用透明 ink 或纯 `GestureDetector`。
