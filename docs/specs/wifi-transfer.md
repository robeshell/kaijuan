# WiFi 传书

## 目标

在同一局域网内，让电脑或另一台设备通过浏览器把图书、漫画文件传入开卷。传输完成后仍然进入统一 `ImportPipeline`，不直接写数据库或正式内容目录。

## 当前 MVP

- 书库「导入 → WiFi 传书」启动临时 HTTP 服务。
- 服务绑定局域网 IPv4 的随机端口，链接带随机会话令牌。
- 开卷界面显示地址和二维码；浏览器页面支持多文件顺序上传。
- 文件先写入 `.wifi-transfer/*.partial`，接收完成后以 `ImportMethod.wifi` 交给统一导入管线。
- 单次最多处理一个上传；导入完成后临时文件立即清理。
- 会话默认 20 分钟，关闭界面或会话过期后服务停止。

## 安全边界

- 这是局域网明文 HTTP，不是互联网服务；页面提示用户只在可信 WiFi 使用。
- 每次会话生成随机令牌；没有令牌、令牌过期或路径不匹配时拒绝请求。
- 服务只提供上传页面、健康检查和上传接口，不提供目录浏览、下载或删除接口。
- 客户端文件名只作为显示名使用，服务端取 basename 并清理控制字符。
- 单文件默认上限 2 GiB；超限在接收前或流式接收中拒绝。
- 上传临时文件不进入正式 `library`，失败或完成后都执行清理。

## 后续

- 上传进度和失败详情更细化。
- 可选的 mDNS 服务发现；MVP 使用二维码和地址，不依赖发现服务。
- 若要支持 HTTPS，需要设计本地证书信任流程；当前不把自签证书伪装成安全传输。
