# 远程来源交互规范

## 边界

开卷支持两类用户自配置的远程来源，但入口和语义分开：

| 入口 | 协议 | 语义 |
|---|---|---|
| 云端存储 | WebDAV | 远程文件系统；管理连接、浏览目录、选择文件 |
| 在线书库 | OPDS | 远程出版目录；浏览分类、搜索书目、选择下载 |

开卷不内置书源、不托管书籍、不提供商城或云同步服务。两类来源共用远程下载队列和 `ImportPipeline`，但连接列表不混排。

## 云端存储（WebDAV）

```text
书库 → 加号 → 云端存储
  → 云端存储管理页
  → 添加 WebDAV / 选择已有连接
  → 填写名称、地址、账号、密码
  → 测试连接
  → 以当前地址作为根目录保存
  → 远程目录浏览
  → 多选 EPUB / CBZ / ZIP 等支持格式
  → 待导入队列
  → 用户点击「导入」
  → 进入队列并立即按序下载 → ImportPipeline → 逐项显示结果
```

连接管理页每行显示名称、地址、连接状态和最近测试时间，支持编辑、重新测试、删除。保存连接不要求当前网络必须可用，但首次添加必须经过一次测试；测试失败时保留表单，让用户修正或稍后重试。

目录浏览只显示文件夹和支持的图书/漫画文件；点击文件夹进入下一级，文件夹右侧的复选框可选择整个文件夹，递归收集其中支持的文件。文件和文件夹都支持跨目录多选；返回按目录浏览历史逐级回退。离开页面或切换连接时，未开始的选择清空并提示，已完成导入不受影响。

## 在线书库（OPDS）

```text
书库 → 加号 → 在线书库
  → 在线书库管理页
  → 添加 OPDS / 选择已有目录
  → 填写名称、OPDS 地址、可选账号密码
  → 测试并保存
  → 目录 / 分类 / 分页浏览，返回按浏览历史逐级回退
  → 可选搜索
  → 选择可下载书目
  → 待下载队列
  → 用户点击「下载」
  → 进入队列并立即开始 → ImportPipeline → 逐项显示结果
```

OPDS 只把带有 acquisition 链接的书目加入下载队列；目录项只负责导航，不当作可导入文件。下载地址、封面和描述来自用户配置的 OPDS 服务，不由开卷托管。

## 统一队列状态

每个远程项目拥有以下状态：`等待`、`下载中`、`导入中`、`已完成`、`失败`。用户在浏览页明确点击「导入/下载」后进入队列并立即开始；失败项目保留错误原因，可单项重试；关闭页面不会中断已开始的单项任务，整个批次完成后显示新增、更新和失败数量。

## 凭据与安全

- 用户名和密码写入平台安全存储，连接记录只保存名称、地址、类型和状态。
- 不允许把凭据写进 URL 并持久化。
- WebDAV 的自签名证书只作为明确的高级选项，不默认放宽 TLS 校验。
- 网络内容先通过流式 staging 和 SHA-256 去重，再由统一导入管线提交。
