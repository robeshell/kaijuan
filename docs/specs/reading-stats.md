# 阅读统计设计规范

**PRODUCT**：[§5.9](../PRODUCT.md)  
**视觉**：[../DESIGN_FOUNDATION.md](../DESIGN_FOUNDATION.md)  
**相关**：[subpages.md](./subpages.md)、[shelf.md](./shelf.md)、[library.md](./library.md)

## 目标

让用户在本地安静地看见「读了多少、最近在读什么」——书房账本，不是打卡社交。

## 范围

### 做（M1 · 书库洞察）

- 在读 / 已读完 / 馆藏本数（与书库进度规则一致：已读完 `progressFraction ≥ 0.98`）。
- 周期：本周（近 7 日）/ 本月（近 30 日）/ 全部 → 影响「期间打开」与最近列表，以及**时长汇总**。
- 最近在读（封面横滑）、已读完短列表。
- 书签合计、划线/笔记合计。
- 点封面 → 打开对应阅读器。

### 做（M2 · 阅读时长）

- 阅读正文已可见、阅读器 route 位于最前、App 前台且非暂停时累计秒数；加载页、错误页、被弹层遮挡、退后台 / 锁屏均停表。
- 按**本地日**写入 `reading_day_stats`；单本累计写入 `reading_item_time`。
- 统计页展示周期内总时长；本周展示近 7 日柱图。
- **听书（TTS）播放中不累计**。
- 可「清除阅读时长」（只清时长表，不动书与进度）。

### 做（M3 · 热力 / 单本 / 备份）

- 近一年日历热力图（跟随产品强调色的 5 级色阶、月标签、一/三/五、带分钟阈值的图例）+ 连续阅读天数。
- 热力图不依赖书库或时长数据是否为空：控制器就绪后始终展示 53×7 格；零数据日期使用可辨识的 0 级格，不能收缩为空组件。
- 窄屏不把 53 周强压到零宽；使用固定最小格宽的横向视口并默认显示最近日期。宽屏采用「年度摘要 + 全年图」双栏，热力格随图表列放大并完整展开，禁止让小图漂在超宽卡片的一角。
- 0 级格轮廓相对卡片背景至少达到 3:1；色阶不只靠颜色，另提供日期明细入口。热力图在读屏树中作为一个摘要图形，不能暴露 371 个逐格焦点。
- 书库详情展示单本累计时长。
- WebDAV 备份/恢复包含 `dayStats` 与 `itemTime`（旧快照无字段视为空）。

### 不做（本能力内）

- 不占第四根 BottomBar Tab。
- 强制每日目标、断签羞辱、社交排行、分享战报。
- 不解析 locator。
- TTS 分钟不计入、不展示「听书时长」。

## 入口与信息架构

| 形态 | 入口 |
|------|------|
| 宽屏侧栏 | 「我的」组：`统计` 与 `设置` 并列；点进内容 Navigator 子页 |
| 窄屏 | **设置** → 「阅读」组 → `阅读统计` |
| 页面类型 | 管理型子页（[subpages.md](./subpages.md)）：侧栏 / BottomBar 常驻 |

根导航仍是三 Tab：书架 · 书库 · 设置。

## 交互

1. 打开统计页 → 聚合书库进度 + 日时长表；流式刷新。
2. 切换本周 / 本月 / 全部 → 更新期间打开、最近列表与时长汇总，无全页 loading。
3. 点最近在读 / 已读完封面 → `openReadingItem`。
4. 空库 → 上半部空态，下面仍展示零数据热力图；若存在删除书籍后遗留的时长，再展示时长汇总与清除入口。
5. 清除时长 → 确认对话框 → 清空日表与单本时长表。
6. 返回 → 内容 Navigator pop。

## 时长采集规则

| 计入 | 不计 |
|------|------|
| 正文 ready + 当前 route + 前台 `resumed` | 加载 / 错误页、route 被弹层覆盖、`paused` / `inactive` / `hidden` / `detached` |
| 分段 flush（约 30s）与退出时 flush | 不足 1 秒的碎段 |
| 跨本地日按日切分 | 听书 TTS **播放中** |
| | 未打开阅读器的停留 |

- 日历窗口按本地年月日构造，不用固定 24 小时的 `Duration(days: …)` 跨日；本周 / 本月均排除未来日期。
- 统计页在本地午夜自动重建日期窗口；App 恢复后定时器也应补刷。

## 状态与文案

| 状态 | 文案草案 |
|------|----------|
| 页标题 | 阅读统计 |
| KPI | 在读 / 已读完 / 馆藏 |
| 时长 | 阅读 X 分钟 / X 小时 Y 分；不足 1 分钟时写「不足 1 分钟」或「暂无阅读时长」 |
| 期间打开 | 近 7 天打开 · 近 30 天打开 · 打开过（全部） |
| 日柱 | 近 7 日（滚动到今天）；无数据日柱高度为 0，标签仍在 |
| 热力图 | 无数据仍展示完整格子；宽屏左侧显示连续天数、活跃天数与年度时长，右侧完整展开全年；窄屏摘要在上、图表默认定位到最近一周；提供轻量「日期明细」入口 |
| 区块 | 最近在读 · 已读完 · 单本时长 · 笔记与书签 · 数据 |
| 清除 | 清除阅读时长… / 确认后不可恢复时长记录，不影响书籍与进度 |
| 空库 | 还没有书籍 / 导入后，这里会汇总在读与读完情况 |
| 加载 | 正在汇总… |

禁止：连续打卡羞辱、听书分钟、社交排行。

## 视觉

- 内容列与设置同宽（`AppSettingsMetrics` / form max width）。
- 浅色纯白 canvas；KPI 与列表用 `settingsGroupSurface`。
- 三枚等宽数字卡；时长用次级强调文案或独立 surface 条。
- 近 7 日柱：单色强调色 + muted 轨道；高度约 96–120；柱下星期缩写；数值可读（语义标签含分钟）。
- 热力卡：标题、摘要、图表与操作共用对齐轴；宽屏（组件可用宽度 ≥ 900）为 220 宽摘要列 + 图表列，窄屏垂直堆叠，不使用四角漂浮信息。
- 热力格：最小可见尺寸 10×10，窄屏间距 3 并横向滚动、星期标签固定；宽屏间距 4、可自适应放大到 24，优先填满图表列。
- 热力色阶从 `ColorScheme.primary` 与当前 surface 混合生成；禁止业务写死绿色，避免默认暖橙强调色与图表形成两套视觉语言。
- 图例逐档绑定色块与阈值文案；「日期明细」使用中性次级按钮，不与页面主操作争夺强调色。
- 周期分段：选中用强调色。
- 封面横滑复用书架语言。

## 数据与路由

| 表 | 用途 |
|----|------|
| `reading_day_stats` | `day` (yyyy-MM-dd 本地) → active / comic / book 秒数 |
| `reading_item_time` | 单本累计秒数（条目删除级联） |
| 既有表 | 条目、进度、书签、划线 |

- UI → `ReadingStatsController` → DB；采集 → `ReadingTimeTracker`（阅读器挂载）。
- `ReadingStatsController` 只有在书库、标注、日时长与单本时长四个初始来源全部就绪后才发布首个快照；流错误进入可重试错误态，不能伪装为空库。
- WebDAV 是用户主动快照，不是实时同步。旧格式日汇总恢复时在本地行与远端行之间选择一条完整且归一化的记录，禁止逐字段取最大值破坏 `active = comic + book`；不会把两个设备的独立累计值相加。
- 路由：`appPageRoute` 推入内容 Navigator。
