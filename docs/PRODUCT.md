## 1. 产品一句话

**开卷：一个本地阅读 App，同一安装包内混排漫画（页图引擎）与图书（reflow 引擎），数据与进度统一管理。**

- 品牌名、图标、包名统一为 **开卷**（`com.kaijuan.reader`，仓库 `kaijuan`）。  
- 用户在同一书库混排漫画与图书，按「类型」筛选，不按品牌切库。  
- 导入常见本地格式；EPUB 自动识别正文图书 vs 页图漫画。  
- **不托管内容、不做账号云、不内置书店**；远程能力仅限用户自配 WebDAV / OPDS 与自备 AI Key。

---

## 2. 产品原则

| 原则 | 说明 |
|------|------|
| **本地优先** | 书与进度默认只在本机；云只是用户自己的 WebDAV / 自备 API |
| **单 App 双引擎** | 一个安装包、一套 `app_library`；`kind` 决定漫画或图书阅读器 |
| **表现层经 controller** | UI 不直连 Drift / 网络客户端 / 安全凭据 |
| **导入两层** | 方式（从哪来）与格式（是什么）分离，统一进 `ImportPipeline` |
| **整理三概念分离** | 书架 ≠ 书单 ≠ 合集，UI 与话术不混用 |
| **阅读沉浸** | 阅读器全屏 chrome；管理页保留根导航 |
| **可关可换的增强** | 系统词典/TTS 不依赖账号；AI 为可选增强（用户 Key） |

| 导入扩展名白名单 | cbz, zip, epub, fb2, fbz, mobi, azw3, pdf, txt, md, markdown |
| 平台 | iOS / iPadOS / macOS / Windows / Android |

### 引擎分叉

| 引擎 | 内容 | 阅读器 |
|------|------|--------|
| **页图** | CBZ / ZIP、页图或固定版式 EPUB | 漫画阅读器（四模式、方向、主题、双页等） |
| **reflow** | 正文 EPUB、FB2、MOBI、AZW3、PDF、TXT/MD 转 EPUB | 图书阅读器（Foliate + 系统 WebView） |

共享：内容哈希去重、不透明 `ReaderLocator`、进度 / 书签契约、controller 分层、设计 token、桌面壳。

## 4. 信息架构

### 4.1 根导航

三 Tab（宽屏 Rail / 窄屏 BottomBar）：

| Tab | 职责 |
|-----|------|
| **书架** | 继续阅读、最近、我的书架（钉选） |
| **书库** | 全部单本；搜索 / 筛选 / 排序 / 管理；**书单**与**合集**为二级 |
| **设置** | 外观、关于、远程与备份入口、阅读统计（窄屏）等 |

补充入口（**不**占第四根 BottomBar Tab）：

| 入口 | 位置 |
|------|------|
| **统计** | 宽屏侧栏「我的」组与设置并列；窄屏在设置内 |
| **搜索 / 书单 / 合集** | 书库侧二级 |
| **导入相关** | 书库加号：本地、自动扫描、WiFi、云端存储、在线书库等 |

### 4.2 导航行为

- 管理型子页（书单、合集、远程来源、备份、统计、导入确认等）推入**内容区 Navigator**：宽屏保留侧栏，窄屏保留 BottomBar。  
- 点根导航目标时先清内容子页栈，再切 Tab。  
- **漫画 / 图书阅读器**走 root Navigator，沉浸式全屏，独立 chrome。  
- 书库单本卡：封面 + 书名；书架用进度条表达续读，不展示文件格式角标作为主信息。

### 4.3 整理三概念

| 概念 | 用户说法 | 用途 | 主形态 |
|------|----------|------|--------|
| **我的书架** | 加入书架 / 钉选 | 想常看见的固定池（全局一个） | 书架横滑封面 |
| **书单** | 书单 | 长清单、按序读 | 目录文字列表；内容竖向长列表 |
| **合集** | 合集 / 分组 | 系列或主题收纳（一盒） | 书库封面尺寸拼贴卡 |

禁止用书单 UI 冒充合集拼贴，或反过来。

## 6. AI（本书智能体）

> 交互与切片验收见 **[specs/ai.md](./specs/ai.md)**。  
> 定位：**围着一本书的可选智能体**，不是全局聊天 Tab，也不是账号云 AI。

### 6.1 一句话

**用户自备 API Key，在「一本书」内完成语言理解、对话、大纲与知识沉淀，并可导出到个人知识库；App 不托管模型、不强制出网。**

### 6.2 原则

| 原则 | 说明 |
|------|------|
| **一书一上下文** | 绑定 `itemId` / `contentHash`；默认不拿整库当上下文 |
| **BYOK** | 用户提供 Key、兼容端点与模型；Key 进安全存储，**不进** WebDAV 备份 |
| **默认可关** | 关闭 AI = 零相关网络请求；语言能力回落系统词典/翻译 |
| **范围与防剧透** | 本书对话优先使用当前作品；无法定位时回退整个文件而不封锁。全书大纲始终基于整本书；知识图谱的未读开关限制生成输入，已保存图谱跨设备完整展示 |
| **工具先于自主** | 词典/翻译多为单步调用；整本译/大纲为任务队列；图谱等再上多步编排 |
| **确定性编排** | 开卷拥有书籍/作品作用域、权限、取消、预算、续写、checkpoint、存储与 UI 状态；模型运行框架只能作为可替换适配层，不接管产品边界 |
| **范围** | v1 仅 **图书 reflow**；漫画 OCR/气泡译 **远** 或另案 |
| **与 TTS 解耦** | 听书继续用系统 TTS；不做云端 AI 音色（见 book-tts） |

### 6.3 能力清单

| 能力 | 状态 | 说明 |
|------|------|------|
| AI 设置（云端 / 本地、Key / 端点 / 模型 / 总开关） | **已有** | 设置 → AI 助手；**云端**（OpenAI / Anthropic / DeepSeek / Grok / OpenAI Compatible 自定义）+ **本地 Ollama**（无需 Key，默认 `localhost:11434/v1`）；测试连接；所有预设服务商与兼容端点统一提供「默认开启深度思考」偏好，本书对话可在「联网」旁按当前面板临时覆盖。App 按服务商协议映射为开关、adaptive 或高低推理强度，并把服务商实际返回的可见过程或摘要作为独立、可折叠内容展示；见 [ai.md](./specs/ai.md) |

## 8. 用户路径

1. **首次**：导入（本地 / 扫描 / WiFi / WebDAV / OPDS）→ 书库 → 打开阅读 → 书架出现续读。  
2. **续读**：书架 → 恢复 locator 进度。  
3. **查找**：书库搜索 / 类型与进度筛选 / 排序 → 打开。  
4. **整理**：加入书架；书单排队；合集收纳系列。  
5. **加深阅读（图书）**：划线笔记、书内搜索、书摘、听书、系统词典/翻译；（规划）本书 AI。  
6. **备份**：设置 → WebDAV 快照备份 / 恢复。  
7. **复盘**：统计页看时长、热力、最近在读。

## 9. 条目生命周期

```text
导入（多方式 → ImportPipeline → 按 format/kind 提交）
  → 书库条目（contentHash 去重）
  → 打开 → lastOpenedAt + progress → 书架继续 / 最近
  → 加入书架 → 我的书架（钉选）
  → 书单成员 / 合集成员
  → 划线 · 笔记 · 书签 ·（规划）AI 缓存与导出物
  → 删除 → 级联清理进度、标注、成员关系；内容文件按引用策略回收
```

身份以 **contentHash** 为准（备份恢复、去重）；不依赖本机绝对路径或自增 ID 做跨设备身份。
